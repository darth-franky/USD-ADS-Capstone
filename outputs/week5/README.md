# Recorded Week 5 experiment outputs

CSV and JSON files record the fixed-protocol historical modeling run. The selected model is determined by 2022–2024 validation scores. 2025 is retrospective assessment data with prior exploratory exposure.

Reproduce from the repository root with `python scripts/build_week5_models.py` and `python scripts/check_week5_sensitivity.py`. Trained joblib objects are excluded; the checked-in predictions support the historical Streamlit explorer.
